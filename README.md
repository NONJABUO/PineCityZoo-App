# 🦁 PineCityZoo App

A responsive, mobile-friendly web application showcasing zoo animals, categories, and search functionality.  
Developed as part of the **FNB App Academy** program.

---

## 📌 Features
- View animals by category (mammals, birds, reptiles, etc.)
- Search functionality for quick animal lookup
- Responsive design for mobile and desktop
- API integration for dynamic animal data
- Interactive and user-friendly interface

---

## 🛠 Tech Stack
**Frontend:** HTML, CSS, JavaScript  
**Backend/API:** API integration for data retrieval  
**Tools:** Git, GitHub, VS Code  
**Methodology:** Agile
